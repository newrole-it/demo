Senior Frontend Engineer

Acme Cloud · Warsaw or remote in Poland · Full-time · 22,000–28,000 PLN a month

Acme Cloud builds a dashboard that 2,000 small online shops use to run their stock, orders and shipping. We are looking for a Senior Frontend Engineer to lead the web app our customers open every morning.

What you will do

  • Build and own features in our Next.js and React app, from the first sketch to production.
  • Grow our design system together with two product designers.
  • Keep the app fast: you watch Core Web Vitals and fix what slows it down.
  • Write tests that catch bugs before our customers do.
  • Review code and help two mid-level engineers grow.

What we ask for

  • 5+ years of building web apps with React and TypeScript.
  • Production experience with Next.js.
  • Automated testing: unit tests with Jest or Vitest, end-to-end tests with Playwright or Cypress.
  • Accessibility: you know WCAG 2.1 and build for keyboard and screen reader users.
  • Performance work on a real product: Core Web Vitals, bundle size, rendering.
  • Experience with a component library or design system.
  • English at B2 or better.

Nice to have

  • GraphQL.
  • Storybook.
  • Mentoring other engineers.

What we offer

  • Fully remote within Poland, with an office in Warsaw if you want one.
  • 26 days off and a learning budget.
  • A small team that ships every day.
